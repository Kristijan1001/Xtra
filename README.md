# Xtra Plus for Twitch

Personal fork of [crackededed/Xtra](https://github.com/crackededed/Xtra), retaining the Kotlin Android UI and features while fixing unnecessary playback, network and animated-chat work. See [battery changes and validation limits](docs/BATTERY.md).

Android package: `com.github.kristijan1001.xtra`, displayed as **Xtra Plus**. It installs alongside upstream Xtra. Current APKs are optimized test builds signed with the upstream test key.

Windows 11 port status and acceptance checklist: [Windows parity](docs/WINDOWS_PARITY.md). Full desktop parity is only complete when the actual behavior in that checklist has been implemented and verified.
